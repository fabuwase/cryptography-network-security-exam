
# Cryptography and Network Security Exam

## Project Description

This project is a small Python security toolkit developed for the Cryptography and Network Security assessment.

The toolkit demonstrates:
- File encryption and decryption
- Decryption verification
- SHA-256 integrity checking
- Detection of changes to a file
- Basic error handling

## Requirements

- Python 3
- Python cryptography library
